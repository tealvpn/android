# Teal VPN for Android

Signed Android releases of [Teal VPN](https://tealvpn.com): phones, tablets, Android TV and Chromebooks.

**[Download the latest APK →](https://github.com/tealvpn/android/releases/latest)**

Also on [Google Play](https://play.google.com/store/apps/details?id=com.tealvpn.client).

## Check the file before installing

1. Compare the file's SHA-256 with the one in the release notes.
2. Check the signing certificate:
   ```
   apksigner verify --print-certs TealVPN.apk
   ```
   It must be:
   ```
   75:68:15:FB:27:4D:04:A3:8E:E8:C9:BD:CA:A7:1D:0A:AE:65:F3:C6:B1:0D:5F:1C:43:BA:F7:D0:DC:8E:8C:24
   ```

Any other signature is not ours.
